# Create Aeronautics — Skybound для MossLauncher

Снимок локальной сборки от 15 ноября 2026 года: **Minecraft 1.21.1**, **NeoForge 21.1.259**, **Java 21**, **395 модов**. Игровые файлы находятся в `pack/`. Полный список файлов, размеры и SHA-256 — в `pack-index.json`.

## Добавление в MossLauncher

1. Откройте **Сборки из GitHub → Добавить сборку**.
2. Репозиторий: `Ujif416/Create-Aeronautics-Skybound`.
3. Ветка: `main`. **Подпапку оставьте пустой**. Имя: `Create-Aeronautics-Skybound`.
4. Нажмите **Синхронизировать**. Требуется скачать около 1,25 ГБ файлов до сжатия.

В текущем MossLauncher синхронизация только скачивает файлы в `<папка игры>/modpacks/Create-Aeronautics-Skybound`. Она **не устанавливает загрузчик и не подключает сборку к запуску автоматически**.

## Подключение к игровому профилю

1. В разделе **Версии** установите Minecraft **1.21.1** с **NeoForge 21.1.259**. В настройках выберите Java **21**.
2. Закройте Minecraft. Используйте чистый профиль этой версии: не смешивайте сборку с другими модами.
3. На карточке сборки нажмите **Папка**, откройте в ней PowerShell и выполните:

   ```powershell
   .\Install-MossPack.ps1 -GameDir 'D:\Minecraft' -VersionId 'neoforge-21.1.259'
   ```

   Замените `GameDir` на **папку игры из настроек MossLauncher**. `VersionId` — точное имя установленного профиля из `<папка игры>/versions/`; если оно отличается от примера, укажите фактическое имя. Скрипт проверяет наличие Minecraft 1.21.1 и NeoForge 21.1.259 в профиле, контрольные суммы сборки и отсутствие конфликтующих файлов до копирования. Существующие отличающиеся файлы он не перезаписывает.
4. Выберите установленный профиль NeoForge на главной странице MossLauncher и запустите игру. Память настройте с учётом доступной оперативной памяти; для начала можно выделить 8 ГБ, оставив запас системе.

Если PowerShell запрещает запуск скриптов, можно перенести файлы вручную: содержимое `pack/mods/` в `<папка игры>/mods/<VersionId>/`, а остальные папки из `pack/` — в `<папка игры>/instances/<VersionId>/`. Делайте это в чистый профиль при закрытой игре. Перед запуском MossLauncher сам копирует моды из `mods/<VersionId>` в экземпляр игры.

## Содержимое и обновление

Включены моды, конфигурации, KubeJS, ресурспаки и шейдеры. Не включены миры, серверные карты, список серверов, история JEI, скриншоты, логи, аккаунты, токены веб-интерфейсов, личные аватары и резервные копии. Исходный профиль Modrinth не изменён. Пользовательские настройки управления и графики из корневого `options.txt` не перенесены; сохранены настройки, предусмотренные сборкой в `config/defaultoptions`.

Кнопка **Обновить** обновляет скачанную копию сборки. Установленный игровой профиль автоматически не обновляется. Для нового снимка используйте чистый профиль или отдельно перенесите изменения, предварительно сохранив свои миры и настройки.

Это пользовательский снимок, а не официальный выпуск авторов сборки или модов. Права на сторонние моды, ресурсы и шейдеры принадлежат их авторам; лицензия на весь набор от имени владельца репозитория не предоставляется.

Проверены целостность экспортированных файлов и структура для синхронизации MossLauncher. Запуск игры через MossLauncher с этим снимком не проверялся.
