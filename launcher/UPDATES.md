# Обновление сборки

1. Загрузите клиентские моды и их зависимости в `pack/mods/` ветки `main`. При замене мода удалите старый JAR. Конфиги размещайте в `pack/config/`.
2. Дождитесь зелёной отметки **Actions → Publish client pack**. Список файлов, SHA-256 и каталог обновятся автоматически.
3. Игроки с MossLauncher **1.0.11 или новее** нажимают **Серверы → Create Skybound → Играть**. Лаунчер проверяет каталог, скачивает изменения и только затем запускает игру. При недоступности проверки запуск блокируется.

На сам игровой сервер моды загружаются отдельно. Не добавляйте серверные-only моды в клиентский набор. Совместимость и необходимые зависимости выбирает владелец сборки; автоматизация проверяет размеры и целостность файлов. Уже работающий Minecraft обновится при следующем запуске.

При красной отметке workflow исправьте причину из журнала и запустите Run workflow либо загрузите исправления. Предыдущая успешно опубликованная версия сохраняется. Ручное редактирование pack-index.json и номера ревизии не требуется.
